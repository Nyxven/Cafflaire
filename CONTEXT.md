## What this is
**Cafflaire**: a mobile + desktop coffee-ordering webapp (hackathon MVP). Customers build their own coffee in a barista-style builder (live SVG cup, caffeine/sweetness/calorie stats, running price), add several drinks to a basket, then check out for pickup or delivery (cash). PHP ₱, integer centavos. Hackathon pitch angle: AI-assisted MVP focused on secure, simple user authentication.

## Security model
Passwords: scrypt hashes. OTP: hashed, 6 digits, 10-min expiry, 5 attempts, 30s resend. Emails/session tokens/OTP identifiers: deterministic AES-GCM (lookups work). Names/phones/addresses/notes/IP/user-agent: randomized AES-GCM. Key = `DATA_ENCRYPTION_KEY` (env only; falls back to derivation from `BETTER_AUTH_SECRET`). Losing the key makes data unreadable. Rate limits on sign-up/sign-in/OTP routes (DB storage). Profile: change password, sign out all devices, delete account. Pre-OTP test users should be deleted (`delete from "user";`). Taste answers (`user_prefs.data`) are encrypted too and cascade-delete with the account.

## Gotchas learned
An absolutely-positioned box with `inset-0 m-auto` that is LARGER than its parent shifts right/down instead of centring (use a square stage + `inset-*`, or translate) · CSS `transition` classes fight framer-motion transforms (don't put both on one element) · hooks can't be called in loops (make a row component, e.g. `SyrupRow`) · browsers block audio until a tap · keyboard activation of a button is `click` with `detail === 0` (used by `useHold`) · No dynamic JSX tags like `<Icon[x] />` (assign to a capitalised variable first) · framer `layoutId` pills need a shared `LayoutGroup` id · `template.tsx` (not `layout.tsx`) is what re-mounts per navigation for page transitions · hand-written drizzle migrations need a matching `_journal.json` entry (and ideally a snapshot) · `sh` has no brace expansion (use bash for mkdir -p {a,b}) · never pipe `next build` into `head` (corrupts .next) · Next 15 `params`/`searchParams` are Promises · page files may only export Next's allowed names · sticky inside CSS grid on mobile needs flex-col · Better Auth does NOT auto-send an OTP on a blocked unverified login (UI requests one) · rate limiting only applies via `auth.handler`, not `auth.api.*`.
